# cf-hub 产品决策

## 已确定

| 决定 | 理由 |
| --- | --- |
| 在项目里保留决定和理由。 | 以后改需求时，可以直接查到当初为什么这么选。 |
| `cf-hub run` 在账号冲突或无法确认目标账号时中止，并说明原因。创建 API Token 时，每个 Token 只授权对应的 Cloudflare 账号。 | 账号隔离优先于命令兼容性。即使指错账号，Cloudflare 那边也有一道权限检查。 |
| 首版按可查到的当日用量排名。用量查不到的账号显示为「未知」，不参加排名。最终部署到哪个账号由用户决定。 | 请求少的账号也可能缺少项目用到的数据库、域名或权限。 |

## 待定

- 用户选定账号后，是自己执行部署命令，还是可以明确授权 Agent 代跑。是否需要 `run` 在终端里要求人工确认。
